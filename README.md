# نظام «عبد القادر العطّار»

نظام إدارة متكامل لمتجر بهارات وأعشاب وبقالة — يجمع المتجر الإلكتروني ونقطة البيع في **مصدر واحد للمخزون**.

مبني على Laravel 11 + Filament 3، بعمارة **Modular Monolith** مع حدود واضحة بين الـ Bounded Contexts.

---

## ١) القرارات المعمارية الحاكمة

| القرار | السبب |
|---|---|
| **النقود = `bigint` بالقروش** | لا `float` مطلقًا. `0.1 + 0.2 ≠ 0.3` تُنتج فروقًا في الفواتير لا يمكن تسويتها. |
| **الكميات = `decimal(12,3)`** | البيع بالوزن (٥٠ جم بهارات) يحتاج كسورًا دقيقة. الحسابات عبر `bcmath`. |
| **المخزون = سجل حركات Append-Only** | `stock_movements` لا تُحدَّث ولا تُحذف (محمي داخل `booted()`). أي تصحيح = حركة عكسية. هذا يعطي Audit Trail كامل. |
| **الطلب = لقطة مجمّدة (Snapshot)** | الفاتورة وثيقة قانونية. اسم المنتج وسعره **وتكلفته** تُجمَّد في `order_lines` لحظة البيع. تغيير سعر المنتج غدًا لا يمسّ فاتورة الأمس. |
| **`cost_minor` مجمّد في السطر** | بدونه، تقرير الربحية التاريخي يصبح كذبة تتغيّر كل يوم. |
| **آلة حالات صريحة** | `spatie/laravel-model-states`. الانتقالات المسموحة معرّفة في مكان واحد؛ الواجهة تعرض الأزرار المتاحة فقط. |
| **`reserved` + `lockForUpdate()`** | يمنع الـ overselling عند الطلبات المتزامنة على آخر كيلو. |
| **جداول Rollup للتقارير** | التقارير تقرأ من `daily_sales_summary` لا من ملايين أسطر الفواتير. |
| **الكاشير لا يرى التكلفة** | طبقتان: `$hidden` في الموديل + `visible()` في Filament. |

## ٥) منطق البيع بالوزن

المنتج الموزون (`type = weighted`, `unit = gram`):

- `price_minor` = **سعر الكيلو** بالقروش. مثال: فلفل أسود ٣٢٠ ج.م/كجم ⟵ `32000`.
- `step = 50.000` ⟵ لا يمكن بيع ٧٣ جم. الكمية تُقرَّب لأقرب مضاعف (سيرفر وواجهة معًا).
- سعر السطر = `price_minor × qty ÷ 1000`.

نفس القاعدة تُطبَّق على التكلفة في `OrderLine::lineCost()` وفي `daily_product_summary`.

## ٦) الضريبة

فئة `VAT_STD` بنسبة **14% شاملة** (`is_inclusive = true`) — كما هو عرف التجزئة في مصر.

الاستخراج من السعر الشامل:

```
tax = total − (total ÷ 1.14)
```

للأسعار غير الشاملة يُضاف المبلغ فوق السعر. المنطق في `PlaceOrderAction`.

## ٧) نقطة البيع

- السلة تعيش في المتصفح (Alpine). السيرفر يُستدعى **مرة واحدة** عند الدفع.
- `idempotency_key` (UUID) لكل عملية ⟵ الضغط المزدوج لا يخصم مرتين.
- الباركود: القارئ يكتب الرقم + `Enter` ⟵ الصنف يُضاف تلقائيًا.
- الإقفال يحسب: `المتوقع = افتتاحي + نقدي + إيداعات − سحوبات`، ثم `الفرق = المعدود − المتوقع`.
  الفرق السالب = **عجز**، وهو أساس المساءلة في تقرير أداء الكاشيرين.

---

## ٨) متوسط التكلفة المتحرك (IFRS)

عند استلام بضاعة، يُعاد حساب التكلفة **قبل** إدخال الكمية:

```
التكلفة الجديدة = (رصيد قديم × تكلفة قديمة + كمية جديدة × تكلفة جديدة)
                  ÷ (رصيد قديم + كمية جديدة)
```

عكس الترتيب يعطي تكلفة خاطئة. انظر `ReceiveGoodsAction`.
